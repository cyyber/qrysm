# Validator Deposit Contract Local Copy

This package contains a copy of the official QRL Validator Deposit Contract along with its ABI, bytecode, and Go bindings generated by go-qrl's [abigen](https://github.com/theQRL/go-qrl/tree/main/cmd/abigen). It contains useful test harnesses for setting up and deploying a validator deposit contract using Go bindings, which are used across tests in Qrysm.
